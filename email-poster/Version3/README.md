# Orchestrator Email Poster — Version 3

Version 3 preserves Version 2's white, sharp, corporate STC visual language and its independently editable content-loading approach.

It restores and condenses the stronger Version 1 narrative:

- explains Orchestrator as a multi-agent digital assistant for internal audit;
- makes the 21 specialist agents and 8 connected workflows immediately visible;
- strengthens the human-in-the-loop review and approval checkpoints;
- distinguishes the solution from a single prompt through connected, traceable outputs;
- emphasizes that AI assists the auditor and creates more time for professional judgment;
- clarifies expected operational impact.

## Files

- `orchestrator-poster-v3.html` — editable poster template
- `orchestrator-poster-v3-content.js` — standalone Version 3 copy source
- `fonts.css` and `stc-logo-white.png` — local rendering assets
- `render.ps1` / `render.mjs` — PNG, email PNG, PDF, and standalone HTML export workflow

Run `powershell -ExecutionPolicy Bypass -File render.ps1` from this folder to recreate the exports.
